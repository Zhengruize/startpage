# 主页

这是一个会让你愣住两秒的新标签页。

当你第一次打开它，看到的不过是一个搜索框、几个快捷卡片、一块天气、一块时钟——干净，克制，像无数个你见过的新标签页扩展。但如果你多停留几秒，事情开始变得不一样：鼠标滑过快捷卡片时，它们像 macOS Dock 栏一样弹性放大，图标本体向上顶起，点击瞬间有一圈蓝色光晕从你的指尖扩散开去；鼠标移到哪儿，一簇淡蓝色的光晕就跟到哪儿，透过毛玻璃卡片隐约可见；打开设置，你以为只有深色模式和搜索引擎切换，直到你在"关于"页面连点版本号十次——一个隐藏的"高级设置"入口弹了出来，里面藏着六个独立可调的圆角参数、天气和时间卡片的自定义跳转网址、卡片显示开关……

这不是一个"又一个新标签页"。这是一个开发者和他的 AI 搭档，用一年零四个月的时间，一行一行磨出来的作品。

---

## 这不是一个"产品"，是一段人机协作史

### 2025 年 3 月：DeepSeek V3 与复制粘贴的黄昏

这个故事开始于 2025 年 3 月的一个晚上。彼时 DeepSeek V3 刚发布不久，没有 Agent，没有项目上下文，没有文件系统访问——每次修改，都要把整个 HTML 文件复制粘贴进对话框，AI 改完，再复制粘贴回来。

就是在这种"手搓"模式下，这个主页的第一个版本诞生了。一个搜索框，十二个快捷卡片，一个天气，一个时钟。没有毛玻璃，没有光晕，没有 Dock 动效，甚至连深色模式都是后来才加的。但它能跑，它好用，它部署到了内网 WebServe 服务上，成了全家人浏览器里的新标签页。

然后代码开始膨胀。从 30K 到 60K，从 60K 到 100K，从 100K 到 140K。HTML、CSS、JavaScript 全部塞在一个文件里，每次修改都要把 140K 的文本喂给 DeepSeek 的对话框。终于有一天，对话框底部弹出了一行灰字：

> 对话过长，请开启新对话。

项目卡住了。开新对话意味着丢失上下文，AI 不知道之前做过什么；不开新对话，它连输入都吃不下。那段时间，这个主页停在了一个"能用但不好看"的状态，像一个盖到一半的房子，脚手架还杵在那里。

### 2026 年：TRAE Agent 让它活了过来

转机出现在 TRAE 的 Agent 模式。Agent 不再需要复制粘贴——它能直接读写工作区里的文件，能记住整个项目的上下文，能在一次对话里连续修改 HTML、CSS、JavaScript 三个文件并保持它们之间的逻辑一致性。

于是这个项目迎来了真正的进化：

- **毛玻璃质感** — `backdrop-filter: blur()` 让卡片和对话框变成真正的半透明玻璃，不再是"一眼望穿"的塑料质感
- **全局光标光晕** — 一个跟随鼠标的淡蓝色径向渐变层，z-index 卡在卡片之上、对话框之下，透过玻璃可见
- **macOS Dock 动效** — 鼠标悬停时，快捷卡片基于高斯衰减函数计算放大倍率，离鼠标越近放大越多，图标本体独立向上顶起
- **点击涟漪** — 点击瞬间，一圈蓝色光晕从点击位置向外扩散，200ms 后才跳转页面，让你看见动画完成
- **触屏全适配** — 三重检测（`ontouchstart` / `maxTouchPoints` / `pointer: coarse` 媒体查询）识别触屏设备，自动禁用光晕和 Dock 效果，换用 `:active` 按压反馈
- **独立圆角系统** — 六个 CSS 变量，六个独立 +/- 控制器，对话框、选择框、输入框、按钮、卡片、图标的圆角互不干扰
- **自定义选择框** — 所有下拉框全部绕过浏览器原生 `<select>`，用 `div` 重写，样式完全自主，连箭头都是手绘 SVG

这些功能里的每一个，都经历过"做了→不满意→推翻重来→再改→终于对了"的循环。光标光晕的 z-index 调了至少五次——一开始在所有元素之上挡住了交互，后来挪到所有元素之下又看不见了，最后才找到"卡片之上、对话框之下"这个恰到好处的位置。玻璃质感也是，一开始只是简单加了个 `opacity`，被吐槽"一眼望穿"之后，才改成现在这套：半透明背景 + `backdrop-filter` 模糊 + 多层阴影 + 暗色遮罩的组合拳。

### 2026 年 7 月 27 日：全平台适配完成

今天，这个项目以 v14.0.0 的版本号部署在内网 WebServe 上，给全家人使用。它在桌面端有毛玻璃、光晕、Dock 动效，在手机上自动切换为触屏交互模式，在老旧浏览器上优雅降级为纯色背景。从 2025 年 3 月的"手搓"到 2026 年 7 月的"全平台适配"，这段路走了一年零四个月。

这不是"我让 AI 写了一个主页"。这是一个人和两个 AI（DeepSeek V3 起步，TRAE Agent 接力）的协作成长史。

## 为什么你要用它

如果你需要的是一个新标签页，市面上有无数选择。但如果你在意细节，这个主页可能值得你多看几眼：

- **快捷网址** — 12 个可自定义的常用网站卡片，支持拖拽排序、添加、编辑、删除，20 个预设图标可选
- **多搜索引擎** — 百度 / Bing / 搜狗 / 360 搜索一键切换，搜索结果可在当前页或新标签页打开
- **实时天气** — 基于 Open-Meteo 免费 API，8 个预设城市，可自定义更新间隔（默认 2 分钟）
- **本地时间** — 实时时钟与日期显示，点击可跳转到自定义时间网站
- **深色 / 浅色主题** — 一键切换，支持跟随系统主题，手动切换后自动覆盖系统设置
- **毛玻璃质感** — 卡片、对话框、输入框全部采用 `backdrop-filter` 半透明模糊，可在设置中一键关闭
- **光标光晕** — 鼠标跟随的淡蓝色光晕，浅色和深色模式可独立开关，触屏设备自动禁用
- **Dock 动效** — 快捷卡片鼠标悬停弹性放大（高斯衰减算法），点击蓝色涟漪扩散
- **触屏适配** — 自动检测触屏设备，禁用鼠标专属效果，启用 `:active` 按压反馈
- **CDN 图标库** — Font Awesome 6.4.0，通过 cdnjs 公共 CDN 加载

## 彩蛋时间

这个主页里藏着一些普通用户不会发现、但极客会心一笑的细节。

### 连点版本号十次，解锁高级设置

在"关于"页面，版本号 `v14.0.0` 看起来只是个普通文本。但如果你在 2 秒内连续点击它 10 次，一个隐藏的"高级设置"入口就会弹出来。里面有打开方式切换、天气/时间卡片自定义跳转网址、六个独立的圆角控制器、卡片显示开关、天气更新间隔——全部可配置，全部持久化到 `localStorage`。

这是对 Android 早期"关于手机"连点版本号解锁开发者选项的致敬。

### 天气卡片和时间卡片，点了会跳转

天气卡片和时间卡片不只是展示用的。点击天气卡片，会跳转到你自定义的天气网址（默认 `weather.com.cn`）；点击时间卡片，会跳转到你自定义的时间网址（默认 `time.is`）。跳转前还有 200ms 的延迟，让你看见点击涟漪扩散的动画——不是为了等什么，就是想让你看见。

这两个跳转网址都可以在高级设置里改。

### 六个圆角，互不干扰

大多数网页的圆角是一个全局变量，改一个全部跟着变。这个主页的圆角是六个独立的 CSS 变量：

| 元素 | CSS 变量 | 默认值 |
| --- | --- | --- |
| 对话框 | `--border-radius-dialog` | 20px |
| 选择框 | `--border-radius-select` | 16px |
| 输入框 | `--border-radius-input` | 16px |
| 按钮 | `--border-radius-button` | 20px |
| 卡片 | `--border-radius-card` | 20px |
| 图标 | `--border-radius-icon` | 50px |

每个变量都有独立的 +/- 控制器，存在 `localStorage` 里，刷新不丢。你可以把图标调成直角、卡片调成大圆角、对话框调成胶囊形——随你组合。

### 所有选择框，绕过浏览器原生样式

这个主页里没有一个 `<select>` 元素。所有的下拉选择框——搜索引擎、城市、图标、时间源——全部是用 `div` 手写的自定义组件：`.select-selected` 显示当前值，`.select-items` 展开选项列表，点击外部自动收起。下拉面板在打开时会被动态移动到 `document.body`，用 `position: fixed` 定位，确保它永远在最上层，不会和下面的元素打架。

为什么不用原生 `<select>`？因为原生的样式在不同浏览器和操作系统上完全不可控，而这个主页的每一个像素都有讲究。

### 毛玻璃的性能取舍

毛玻璃效果用的是 `backdrop-filter: blur()`，这个属性在 Chrome 上有已知的性能开销——它需要实时对背景内容做高斯模糊。但这个主页的使用场景是"新标签页"：用户打开它，搜索一个东西或点一个链接，然后离开。典型的停留时间在 10 秒以内。在这个时间尺度上，`backdrop-filter` 的开销可以接受。

如果你在老旧设备上感到卡顿，设置里有一个"玻璃质感效果"开关，关掉之后所有 `backdrop-filter` 会被 `!important` 覆盖为 `none`，卡片降级为纯色背景。性能优先，美观其次。

### 光标光晕：跟随你，但在触屏上消失

深色模式下，鼠标周围会有一簇淡蓝色的径向渐变光晕，跟随你的鼠标移动。它的 `z-index` 设定在卡片之上、对话框之下，所以你可以透过毛玻璃卡片看到它——就像一盏灯隔着磨砂玻璃在移动。

但如果你用手机打开这个页面，光晕会消失。触屏设备检测用的是三重判断：`'ontouchstart' in window`、`navigator.maxTouchPoints > 0`、`window.matchMedia('(pointer: coarse)')`。只要任一条件命中，光晕、Dock 悬停效果全部禁用，取而代之的是 `:active` 按压缩放和更短的过渡时间。

## 技术栈

纯静态页面，零构建工具，零依赖框架：

- **HTML5** — 语义化结构，`viewport-fit=cover` 适配刘海屏
- **CSS3** — CSS 变量驱动主题系统，`backdrop-filter` 毛玻璃，Grid / Flexbox 布局，`cubic-bezier` 弹性曲线
- **原生 JavaScript（ES6+）** — 无 jQuery，无 Vue，无 React，全部手写
- **Font Awesome 6.4.0** — cdnjs 公共 CDN 加载
- **Google Fonts Inter** — 可变字重，300-800
- **Open-Meteo API** — 免费、无需 API Key 的天气数据源

## 项目结构

```
├── index.html              # 页面结构（模态框、设置面板、快捷卡片容器）
├── css/
│   └── style.css           # 全部样式（主题变量、毛玻璃、光晕、Dock 动效、触屏适配）
├── js/
│   └── script.js           # 全部逻辑（主题切换、Dock 效果、光晕跟随、触屏检测、圆角控制、彩蛋）
├── favicon.ico             # 网站图标
└── README.md               # 你正在看的这个文件
```

三个文件，各司其职。没有构建步骤，没有 `node_modules`，没有 `package.json`。把整个文件夹丢到任意静态文件服务器上就能跑。

## 使用方式

```bash
# 方式一：Python 内置服务器
python3 -m http.server 3000

# 方式二：Node.js 静态服务器
npx serve

# 方式三：直接双击 index.html（部分浏览器功能可能受限）
```

浏览器打开 `http://localhost:3000` 即可访问。

所有设置（主题、搜索引擎、快捷网址、圆角参数、光晕开关等）都存在浏览器 `localStorage` 里，换设备不会同步，清缓存会重置。

## 写在最后

这个项目没有一个专业设计师参与，没有一行代码是"我"独立写的。它是一个普通人和两个 AI 工具——DeepSeek V3 和 TRAE Agent——在一年零四个月里的协作产物。

DeepSeek V3 负责让它从零到一，在复制粘贴的泥潭里搭起了骨架。TRAE Agent 负责让它从"能用"变成"好看"，从"桌面端能用"变成"全平台适配"。中间有无数次推翻重来：光晕的 z-index 调了五次才找到对的位置，玻璃质感被推翻重写了三遍才有了真正的折射感，Dock 效果的放大倍率来来回回改了四轮才收住那个"果味"。

每一次修改，都是人和 AI 之间的一次对话。有时候是我说"这个不对"，有时候是 AI 说"这里有个边界情况你没考虑到"。更多时候，是我们一起发现了一个更好的做法——那种"诶，这样确实更好"的瞬间，是这个项目里最珍贵的部分。

如果你也在找一个有温度的新标签页，或者你想看看人和 AI 一起能做到什么程度，欢迎试试。
